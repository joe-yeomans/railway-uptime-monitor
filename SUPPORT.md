# Support

## Getting help

For usage questions and troubleshooting:

1. Check the README first: setup, required variables, and common run commands.
2. Search existing issues for similar problems.
3. Open a new GitHub issue with reproduction details.

## What to include in support requests

- Bun version (`bun --version`)
- Operating system
- Relevant `.env` keys used (redact secret values)
- Logs from startup/check loop
- Any recent code or config changes

## Security issues

Do not open public issues for security vulnerabilities. Follow `SECURITY.md`.

## Feature requests

Open a GitHub issue and include:

- Problem statement
- Proposed solution
- Alternatives considered
- Expected operational impact
