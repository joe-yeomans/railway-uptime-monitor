# Security Policy

## Supported versions

This project is currently under active development. Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not report security issues in public GitHub issues.

Report vulnerabilities via a private GitHub security advisory for this repository.

Include:

- A description of the issue
- Impact assessment
- Steps to reproduce
- Any proof-of-concept details

You can expect an acknowledgment as soon as practical.

## Scope

Please report issues related to:

- Authentication or authorization bypass
- Sensitive data exposure
- Injection vulnerabilities
- Remote code execution
- Dependency vulnerabilities with practical exploit paths

## Disclosure

After a fix is prepared and released, coordinated disclosure is welcome.
